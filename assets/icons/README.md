# 稲作カルテのアプリアイコン

2026-11-12に承認された、太陽と収穫前の稲田のデザイン。

- 原画: `rice-sun-source-v1.png`
- PWA: `rice-sun-v1-192.png` / `rice-sun-v1-512.png`
- Appleホーム画面: `rice-sun-v1-180.png`
- favicon: `rice-sun-v1-32.png`
- 再生成: `tools/build_rice_icons.ps1`

原画は組み込み画像生成ツールによる編集。承認済みの画像をコピーして保存し、各サイズはSystem.Drawingで縮小している。旧 `icon-192.png` / `icon-512.png` は復旧用に保持。

最終生成指示: 黄金色の垂れた稲穂、青空、左上の太陽、規則的な稲株の構図を保ち、水面・水たまり・反射・波紋をすべて除く。刈り取り前に落水した田んぼとして、株元の土、稲株の列、遠方の畦を描く。砂漠のような亀裂にはしない。大きな星形の輝きを除去し、太陽の過度な光線を抑える。稲穂と葉に当たる自然な黄金色の日差しで輝きを表す。文字・透かし・枠・描き込んだ外周角丸は加えない。

maskableアイコンの安全領域は保証していないため、manifestでは `purpose: any` とする。インストール済みのホーム画面アイコンはOS側のキャッシュにより更新が遅れる場合があり、ブラウザーでの画像更新と区別する。アイコン変更のために利用者の記録を削除・初期化しない。

確認: PNG4サイズの実寸、manifest/favicon/apple-touch-icon/通知/SW参照、HTTP取得、Chrome画像デコード、32/48/64pxの表示を主担当と独立監査で確認。
