# 収穫・出荷と共通の表示ルール

承認基準画像: [収穫・出荷とホーム](ui-reference/20261112-harvest-home.png)

画像は文字・数値・縦明細の配置基準。画像中の通知・人物アイコン、サンプル数値をアプリへ追加しない。下部ナビゲーションは既存の6項目を維持する。

## 入口と元データ

管理画面の「収穫・出荷」を共通入口にする。年産と品種の選択を保ちながら、既存の収量入力、出荷入力、詳細・編集・削除へ移動できる。従来の結果、対応費、販売先単価の管理も詳細から到達可能とする。

新しい集計は読み取り専用。収量は `millingRecords`、出荷・販売・おすそ分けは `shipments`、反収は既存の `harvestPerformanceFor`、参考残量は既存の `riceStockFor` を参照する。旧 `varietyResults` を新収量へ加算しない。保存形式の移行・初期化は行わない。

1俵は60kg。数量・単価は既存レコードの保存値を使い、単価や等級を追記しても新しい出荷を作らない。白米を玄米へ自動換算しない。品種未設定や数量不足の履歴を推測して加算しない。集計対象外がある場合は折りたたみの外に注意表示する。

### 自家用（ver314）

自家用に取り分けた量は `shipments.kind: household` として保存し、おすそ分けと分離して表示する。年産・品種・日付・袋重量・袋数を指定する。販売先、単価、等級の入力は不要。玄米の自家用分は出荷に回せる参考残量から差し引くが、収穫量・反収・売上は変えない。家族が実際に食べた量や、家の中の物理的な在庫を日々管理する機能とは区別する。

自家用記録も編集・削除・取消・JSON入出力の対象。既存記録を自家用へ自動変換しない。白米は従来どおり玄米へ自動換算しない。自家用だけでは年度締めに必要な出荷・販売・配布の実績を満たさない。

### 年産の販売額合計（ver315）

「お米の行き先」の一覧上部に、選択中の年産の販売額合計を大きく表示する。全相手先・全品種の出荷と販売が対象。相手先検索や区分の絞り込みでは、この年産合計を変えない。全収穫年を選択した場合は全収穫年の合計と明示する。

単価と袋内訳から計算できる記録だけを合算し、おすそ分け・自家用を除外する。単価未登録・袋内訳未登録の件数を添える。記録なしは0円、全件未計算は「未計算」、明示的な単価0円は計算済み0円と区別する。表示のために記録を変更しない。

## 表示

- 関連する数量は縦の明細。項目名と右揃え数値を一行ずつ配置する。
- 主要値、単位、本文、補足の強弱を分ける。全体を太字にしない。
- 短い年月日表示を使い、日付と履歴名の重なりを防ぐ。
- 長い予測日・説明は小さく押し込まず、十分な行幅を使う。
- ホームは専用の出穂確認日・幼穂長実測日から経過日数を表示する。手動ステージ選択を出穂確認へ置き換えない。
- ホームの詳細説明はカード展開時に見られる。積算気温・水管理の既存入力や元の判定を変更しない。
- メニューやフィルターなど選択のための段組は維持する。

## 検証

`tools/verify_harvest_ledger.js` は年産分離、旧結果の保持、単価変更での二重減算防止、参考残量、等級・出荷先情報を確認する。

`tools/check_readable_ui.cjs` は360px・390px・1280pxで実データ形式の検証記録を使用し、120俵−販売100俵−おすそ分け5俵＝15俵、10aあたり10俵、売上200万円の集計、参照時の非変更、入力からの戻り、ホームと主要画面のはみ出しを確認する。

独立監査は `tools/check_harvest_ledger_mobile.cjs`。既存の全マスター遷移は `tools/check_ui_rhythm_mobile.cjs`。

検証用データは独立したブラウザーにのみ登録する。本番端末の記録には触れない。

## 確認結果（2026-11-12 / ver312）

- 自動回帰97本成功、変更JSの構文・差分チェック成功。
- 360px・390px・1280pxで主要画面の表示、集計値、管理13項目からの遷移・戻る、振り返りの切替、入力からの復帰を確認。
- 独立監査で360px・390pxの収量・出荷の登録、等級・単価の編集、削除確認、取消、年産・品種分離、旧設定保持、再読込を確認。
- 既存の出荷テストも360px・390px成功。数量と単価の変更、販売先単価、贈答の売上除外、取消・削除・戻るを確認。
- 未反映件数と負在庫の注意は詳細を閉じたまま表示される。独立監査で画像も確認済み。
- 既存の重複している手入力結果は削除・加算・自動移行していない。
