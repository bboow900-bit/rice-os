# 収穫実績の振り返り / 20261114_ver319

## 表示の責務

- 年間履歴の稲刈りカードから、既存の実績詳細へ入る。
- 圃場別の作業者評価、見立てた適期、日程の事情、判断メモを最初に表示する。
- 収量と保存済みの出穂後積算温度は別枠で表示する。
- 複数圃場の共有収量・観察は共通値と明記し、個別圃場へ配分しない。
- 保存済みの事前見通しとの比較は `state.harvestForecastComparisonFor` の検証済み範囲だけを使用する。
- 日程差は「目安期間の終了から○日後」と表現する。現場判断と混同する「刈り遅れ」判定は行わない。
- 欠測や旧形式の積算値は注意表示を付けて残す。検証できない旧値を予測比較の根拠にしない。
- 来年に引き継ぐ材料は入力済みの事実のみを要約する。因果関係や作業指示を生成しない。
- 水管理・天気・測定条件・詳しい根拠は既存の内容を折りたたみで確認できる。
- 独立していた「収穫済み・今年の一区切り」パネルは年間履歴の上部に表示しない。年度締め機能は変更しない。

## 保存と編集

新しい保存項目、移行、予測再計算、自動保存は追加しない。表示モデルは読み取り専用。
既存の編集画面を再利用し、編集ボタンでは刈取時期評価の項目を開く。
再取得・完了確認は利用者が既存ボタンを明示的に押した場合だけ実行する。
Google Drive関連の中断中の変更は今回の対象外。

## 確認

- `tools/verify_harvest_review.js`: 保存互換性、共有範囲、旧積算値、検証済み比較、表示時の非更新。
- `tools/check_harvest_reflection_primary.cjs`: 360 / 390 / 1280px、稲刈り詳細、戻る、表示・保存値の維持。
- `tools/check_annual_story_primary.cjs`: 既存の大きい節目イラスト、保存済み積算値、詳細と戻る。
- `tools/check_review_unified_primary.cjs`: 共通水管理入力、台帳、編集取消、数量の保存。
- `tools/check_harvest_record_reflection_mobile.cjs`: 独立レビュー。360 / 390 / 1280px、現場評価と参考期間差、共有範囲、圃場・年産分離、編集戻り、完了確認の取消、積算再取得の取消を確認。

既存の固定圃場選択欄が基本情報を覆うスクロール位置は残る。今回の収穫詳細の評価・数値・編集操作は確認済みだが、固定欄全体のレイアウト解消は今回の対象外。

ネット上の一般的な適期を追加して断定する改修ではない。条件不足の場合は比較不可を表示する。

## 20261114_ver320: 年間履歴での表示復旧

ver319では旧まとめを取り除いた一方、新しい収穫の振り返りを稲刈り詳細内だけに配置したため、年間履歴の概要から収穫情報が見えなくなった。利用者のスクリーンショットで配置の取り違えを確認した。実行時エラーによる空白とは区別する。

年間履歴の「収穫・出荷」の直下に、現在の圃場・年産の最新の実際の稲刈りを要約して表示する。同じ読み取り専用モデルを再利用し、現場評価、収量、保存済み積算、参考比較を表示する。作業メモなどは引継ぎ材料の折りたたみで確認する。部分刈取を年度全体の完了とみなすことはしない。詳細ボタンは既存の稲刈り詳細へ接続する。

再発防止として、詳細だけではなく年間履歴自体にまとめが存在すること、そこから詳細・編集・戻るへ進めることもブラウザー検証に追加した。保存形式・入力値・年度締めは変更しない。
