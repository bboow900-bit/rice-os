# 除草剤体系と資材購入履歴

## 境界

- 除草剤体系は管理タブの独立マスター。体系の確認と入力・編集を別表示にする。
- 既存の `meta.herbicidePrograms` / `herbicideAssignments` / `herbicideObservations` を引き続き使用する。
- 圃場には表示年度の有効な割当を表示する。体系の計画と実際の散布記録は別扱い。
- グループ設定は既存の圃場ID別スナップショットを維持し、グループ変更で過去の記録を付け替えない。

## 資材購入

資材の `purchases` に安定した `purchaseId` を持つ購入履歴を追加する。
年度、購入日、仕入先、数量、単位、税込単価、税込実額、メモを保存する。
未入力の価格は0円に変換しない。購入履歴から旧来の購入数・在庫数・使用数を自動上書きしない。
購入履歴ありの資材全体削除は拒否する。購入履歴自体の編集・削除は専用操作で行う。
JSON統合は同一資材の未登録購入IDを追加し、同一IDは現在の値を優先する。
統合は履歴を復元する操作なので、削除済み履歴が古いバックアップから戻る場合がある。
置換取込と統合取込は従来どおり区別する。

## 開閉記号

`details.form-section` の矢印指定を直下の `summary` に限定する。
入れ子の閉じた項目に外側の開いた状態の▼を重ねない。
実際に開閉する項目と選択欄の矢印は残す。
