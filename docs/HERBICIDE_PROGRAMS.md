# 除草体系・年度別実績

更新: 2026-09-08 / ローカル実装（未プッシュ）

## 操作経路

1. 管理 → 資材台帳 → 除草体系・年度設定で体系を作成する。
2. 初期剤・初中期一発剤・中期剤・後期剤、または任意区分を追加し、資材・時期・選択理由を設定する。
3. 年度と個別圃場またはグループに体系を割り当てる。
4. 作業入力で「除草剤」を選び、詳細入力の体系選択から実施した処理を指定する。実際の使用理由は変更できる。
5. 振り返り → 除草体系・効果の振り返りで計画・使用実績・経過観察を確認する。実績ボタンは既存の履歴詳細へ移動する。

グループ内の体系が異なる場合は、共通処理を推測して割り当てず個別選択とする。

## データ保護

- 保存キーと既存の作業データ構造を維持する。追加データは `meta.herbicidePrograms`、`meta.herbicideAssignments`、`meta.herbicideObservations` に保存する。
- 作業との関係は `herbicideLinks` の圃場・年度・割当・処理IDで保持する。作業を複製しない。過去記録は名前だけで自動紐付けしない。
- 年度割当時に処理内容・資材名・登録番号・見直し年数を保存する。体系変更前の割当と観察は履歴として保持する。
- バックアップ統合時は各IDで統合し、同一圃場・年度の有効割当を一つに整理する。元のバックアップは変更しない。
- 3年は見直し設定の初期値であり、必須の交換周期や農薬使用基準として扱わない。

## 未実装

2026-09-09方針: 製品情報の自動取得・転載は保留。登録番号と農林水産省の農薬登録情報へのリンク、利用者が登録するメーカー製品ページのURLを表示する。外部ページを取得・転載せず、使用期限や適用雑草を推測しない。

資材の「使用カルテ」には資材IDで紐付いた当該年度の実績・使用理由・メモと関連する除草体系の観察を表示する。数量は入力された文字列を維持し、異なる単位を自動合算しない。製品ページのURLは利用者登録であり、アプリが公式性を保証した表示にはしない。

在庫の自動引き落とし、異なる単位の数量合算、農薬使用可否の自動判定、マニュアルPDF生成は本変更の対象外。
