# イラストを使うホームと振り返り

## 変更範囲

ホーム、振り返り、年産別収穫成績の表示と、共通のブランド見出し・下部ナビの見た目だけを調整する。
保存形式、記録の読み取り条件、計算、年度区分、編集・削除、予定との紐付けは変更しない。
下部ナビ6項目と既存の記録追加・水管理入力・詳細・戻る導線を維持する。

## イラスト

- `assets/images/ui-pop/rice-sowing.png`: 4月の播種・育苗。
- `assets/images/ui-pop/rice-growing.png`: 7～8月の生育期。機械のいない田んぼ。
- `assets/images/ui-pop/rice-processing.png`: 11月の調製・出荷。米袋と出荷準備の風景。
- `assets/images/ui-pop/rice-winter.png`: 12～3月の来季準備。
- `assets/images/ui-pop/harvest-rice.png`: 稲穂。振り返り、収穫成績、ブランド見出し用。
- `assets/images/ui-pop/rice-transplanter.png`: 田植え機。苗載台の向きを修正し、利用者確認済みの絵。
- `assets/images/ui-pop/rice-combine.png`: コンバイン。オーガの支点・排出口の前後を修正し、利用者確認済みの絵。

いずれも新規生成した透過PNG。機械の修正前の絵は使用しない。装飾画像はスクリーンリーダーへ重複して読ませない。
イラストは季節感・役割の目印であり、現在の生育状態を実測として断定するものではない。
既存の圃場ステージアイコン、実際の作業・水管理表示はそのまま利用する。

ホームのみ、`assets/js/ui/season-art.js` の月別定義により見出しの絵を切り替える。
5～6月は確認済みの田植え機、9～10月は確認済みのコンバインを使用する。
これは暦に合わせた装飾であり、実際の作業日や圃場の生育判定には使わない。
振り返り・収穫成績・履歴の絵は画面の役割や作業内容に合わせ、今日の季節で一律に変更しない。
管理・カレンダーを含む全画面の全面変更ではない。

## 見た目

白・明るい緑を基調に、水管理の青と収穫の稲穂色を使う。
画面を飾りで埋めず、実際の数値、期間、押せる操作が先に読めることを優先する。
長い名前、未記録、全件収穫済み、空状態でも架空の値を補わない。
動きは押下の短い反応にとどめ、動きを減らす端末設定を尊重する。

## 確認

閲覧のみでは本データに変更がないことを隔離データで確認する。
