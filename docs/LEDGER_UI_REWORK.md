# 台帳・資材・播種機・振り返りの整理

Google Drive連携は一時中断したまま。本改修で連携作業・外部送信は再開しない。
作業ファイルは残すが、未検証のDrive連携スクリプト・UI・キャッシュ参照は今回の画面から外す。
公開済みの端末内保存・JSON共有を維持する。利用者の承認後に独立した更新としてプッシュする。

## 共通方針

一覧は分類・年度と主な情報だけ、詳細は読み取り専用、登録・編集は別表示とする。
取消と戻るは元の詳細・一覧へ戻り、未保存の編集で元データを変更しない。
既存の機械メンテ・出荷・除草体系・圃場の分離済み導線は維持する。

## 資材と購入

分類に殺虫殺菌剤・培土・マットを追加。従来の防除剤や未知分類は保持する。
一覧・資材詳細・資材入力・購入一覧・購入詳細・購入入力を排他的に表示する。
購入一覧は全資材を横断し、年度と親資材の分類で絞り込む。
仕入先、数量、税込単価・実額、メモは既存の購入記録を使用する。
0円と価格未記録を区別し、旧在庫・旧購入数を自動加算しない。

## 播種機

`meta.seederProfiles` に安定したIDを持つ年度別設定を保存する。
慣行・密苗という播種方法と、培土・マットという育苗床を分離する。
催芽籾g/箱、床土cm、覆土厚cm、覆土後の縁との隙間cmを別々に記録する。
灌水・送り速度・播種ダイヤル、育苗箱、量り取り、資材・品種と意図・メモを任意で残す。
推奨値を自動設定せず、乾籾から催芽籾への固定換算も行わない。
年度コピーは新IDとし、既存年度を上書きしない。JSON統合は同IDを既存優先で保持する。
実作業へ当時の設定を保存するためのsnapshot APIを用意する。作業入力への自動転記は後続作業。

## 振り返り

同じ実績を主要な記録／日常作業／全履歴で切り替える。別台帳へ複製・移動しない。
草刈り・見回り・清掃と節目でない生育観察は日常扱い。未認識の独自作業は隠さない。
保存済みreviewImportant=trueは一覧・一年の流れ双方で優先する。
実測の幼穂・出穂・現場ステージ、水管理の期間、田植え・収穫を保持し、予測は履歴へ追加しない。
一覧は日付・作業名・主要情報1件に統一し、詳細から編集へ進む。
使用資材は名称・使用回数・期間を概要にし、個々の使用記録は折りたたみ内で確認する。
数量の異なる単位を合算せず、購入と使用を混同しない。

## 管理の画像

資材・除草体系、機械メンテ・トラクター、収量・出荷の画像重複を解消する。
新規の除草体系表と整備工具は既存の手描きイラストに合わせる。
播種機は苗箱、収量は米袋、出荷は調製・出荷準備の絵を使う。

## 台帳ごとの導線

- 資材・購入：分類と年度の一覧 → 読み取り詳細 → 新規／編集を排他表示。
- 栽培レシピ：一覧 → 読み取り詳細 → 明示保存する編集。変更途中の自動保存を廃止。
- トラクター・田植え機設定：一覧 → 詳細 → 編集。編集時に一覧や対象切替を同時表示しない。
- 収量・在庫／旧品種結果／出荷対応：各一覧・詳細・入力を分離。編集中の台帳切替は取消確認。
- 水管理：管理からは年度・対象・種類で確認する一覧、詳細、編集へ。ホーム・作業入力の入水／落水は従来どおり入力へ直行。
- 機械メンテ、除草体系、出荷・配布、圃場の既存分離は維持。
