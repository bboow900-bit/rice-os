# 資材・除草の振り返りと年間履歴UI

## 2026-11-17 実装記録

利用者が承認した途中画面を基準に、本体の年間履歴へ統合した。生成した参考画面ではなく、実際のHTML/CSSと保存済みデータから描画する。

### 画面と導線

- 圃場の振り返りに、イラスト付きの「資材・除草の振り返り」入口を設置。
- 詳細は「除草の結果」「体系と実績」「使用資材」の3タブ。
- 結果は登録済みの観察・雑草・メモを表示。使用実績から効果を自動判定しない。
- 観察の追加・編集は表示と分離し、既存の保存処理を使用。削除は対象を限定して確認する。
- 実績カードは既存の作業詳細へ遷移し、戻ると元のタブへ戻る。
- 製品マスターを開いた場合も、戻る操作で元の振り返りへ戻る。
- 未保存の変更があるときは、タブ・圃場・画面の移動前に破棄を確認する。

### データ保護

- 保存形式やDB移行は変更しない。描画だけでは保存しない。
- 圃場・年度・明示的な体系リンクを使い、別圃場や予定を使用実績として推測しない。
- 使用時の保存名、旧体系の記録、既存の雑草配列を保持する。
- 年度と暦年が異なる既存の明示リンクを読み取れるよう互換性を確保。新規入力の年度ルールは変更しない。

### 振り返り全体の外観

年間入口・圃場選択・作業資材サマリー・前年比較・気づき・引き継ぎを、緑の見出し、稲のイラスト、白い本文、金色のメモへ統一した。「一年の流れ」の配置や下部ナビは維持する。
