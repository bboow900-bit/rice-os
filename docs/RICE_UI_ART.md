# 稲作カルテの画像ルール

新規・差し替えのイラストは、承認済みの[田んぼの水彩原画](ui-review/watercolor-reference.png)を共通の見た目の基準とする。画面上での配置は「振り返り → 圃場の一年 → 年間履歴」を参照する。

- 筆で水を含ませて描いたような色のにじみ、淡い重ね塗り、塗った部分の紙目を残す。遠景は柔らかく、手前の稲や機械は判別できる程度に筆の形を残す。機械的なぼかしや光彩で代用しない。
- 全画面の装飾イラストを用途別に揃える。順にホームの季節画、年間履歴の作業画、圃場・見通しの生育画、資材・管理・ナビの小さな絵を確認する。記録写真、機能記号、ステージ別の配色・判定は変更対象外とする。

- 水彩画をそのまま貼るのではなく、外縁や足元を淡くぼかし、にじみがカードの地色へ自然に消えるように仕上げる。四角い画像の境目や切り抜きの輪郭を残さない。
- 絵全体を均一にぼかさず、作業や生育段階を見分けるための主役の形・要点は残す。写真風、太い輪郭、強い光彩は混ぜない。
- 作業・生育段階と絵の内容を一致させる。幼穂確認は葉鞘の内側、出穂確認は田んぼ全体で穂が出始めた姿。内容を特定できない記録に別作業の絵を付けない。
- 文字と操作領域には重ねず、イラストだけのためにカードを高くしない。予定登録はコンパクトな文字主体とする。
- 360pxと390pxの実画面で、文字の折り返し、絵の見切れ、カードの操作を確認する。
