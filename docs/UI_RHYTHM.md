# 共通UIの整理（2026-11-07）

## 振り返りの年度・一覧表示（2026-11-09 / ver308）

- 対象年度の選択を大きな独立行にし、単年度の一覧は月日を中心に表示する。
- 全年度、実施年と作付年度が異なる記録、年度をまたぐ期間は年を残す。詳細・編集・削除確認の日付は省略しない。
- 作業、資材、生育、水管理、写真の一覧を同じ日付方針に揃える。対象圃場名と既存の詳細への導線は維持する。
- サマリーの固定寸法を避け、見出し・数値・単位と次の区画が重ならない高さを確保する。スマホの主要件数は2列、PCは3列とする。
- 表示のみの変更で、登録済みの年度や記録データは書き換えない。

## 保持するもの

既存のイラスト・季節テーマ・6項目の下部ナビ・画面遷移・保存形式を維持する。
履歴の実績と予測、水管理の青、注意色、削除操作の色を装飾色に置き換えない。
Google Drive連携は再開しない。

## 情報の優先順位

1. 圃場名、現在の状態、主要な数値。
2. 主操作と、記録・編集への入口。
3. 補足説明、件数、設定内容。

画面見出し22px、セクション18px、主情報17〜18px、本文14px、補助12pxを基本にする。
タッチ操作は原則44px以上、主要な保存操作は48px以上。入力文字16pxで端末の自動ズームを避ける。
カードは8pxの角丸、余白・境界線・控えめな色で区別し、カード内に装飾カードを重ねない。

## 対象

- ホーム：圃場ごとの区切り、現在状態、根拠の読みやすさ。
- 圃場：主情報と除草体系を分離し、合計面積・フィルターは補助情報にする。
- 振り返り：収穫成績と年度締めを維持。締め前確認・作業時期・設定検証はメイン一覧の後へ。
- 管理：既存14ボタンを4つの用途見出しで整理。各遷移先は変更しない。
- 入力と詳細：入力欄、保存ボタン、項目と値、メモの余白を統一する。

変更は `ui-rhythm.css` を中心に隔離し、旧タイムラインの日付配置や日数計算には触れない。
隔離データで360px・390px・1280pxの表示、各管理ボタンと戻る、編集取消、保存データ不変を確認する。

## 確認結果

- 85件の自動検証成功。
- 360px・390px・1280pxで主要画面の描画、横はみ出しなし、管理14入口、振り返りタブ、作業入力と戻るを確認。
- 圃場マスターは従来どおり独立タブのため管理タブで復帰。他13入口は戻るボタンで復帰。
- 機械設定の詳細・編集・取消、水管理の履歴・編集・保存失敗時保持・グループ入力をスマホ両幅で回帰確認。
- 閲覧と取消で保存データが変わらないことを検証。実端末・公開先での確認は未実施、プッシュ前のローカル版。

## 対象と不足理由の明示（ver305）

- ホームの不足理由を田植日未登録・出穂日未登録・気温取得失敗・対象期間の気温なしに分離。
- 収穫後は収穫時積算と当年の振り返りメモ有無を表示。水管理の進行表示は外す。
- 振り返りの固定圃場切替に閲覧年度を併記。詳細は個々の記録の年産も表示し、実施日の暦年と区別。
- 長文メモでも切替が画面内に残るよう、振り返り詳細に限定してstickyを妨げるoverflowを整理。
- 作業・生育・中干し・水管理の保存通知に対象名と実際のユニーク圃場数を明示。保存される記録内容は同一。
- 全86自動検証成功。360px・390px・1280pxで年またぎ年産、同日12作業、長文メモ、空圃場、収穫後表示を確認。
- 閲覧・切替段階の保存データ不変と、実フォームからの2圃場保存・件数通知の一致を別々に検証。実端末・公開先は未確認。

## 振り返りサマリー・対象圃場（ver307）

- 旧スマホCSSの3列固定・nowrap・47px圧縮・9pxラベルを解除。数値・単位を折り返し可能にし、内訳はスマホ2列、600px以上3列。
- サマリーの枠を内容に合わせて伸ばし、見出しと節目日付のコントラストを改善。集計条件や数値は変更しない。
- 簡潔な作業履歴へ対象圃場名を追加。複数圃場は重複除外、圃場外・対象未確認を区別。資材名・機械名は保持し、圃場名の二重表示は抑止。
- 文字と枠、ラベルと値、数値と単位、節目ラベルと日付の座標を検証。長い作業時間・全年度の日付範囲・多桁値・600px切替境界を対象にする。
- 履歴カードから実績詳細へ進み、戻っても保存データが不変であることを確認する。公開後の実端末確認は別途必要。
